# 🛍 SSARAFOS — Telegram-магазин брелоков

Готовый бот: каталог, корзина, оформление заказа, онлайн-оплата через ЮKassa,
админ-панель со статусами заказов и API для бота ВКонтакте.

---

## ✨ Что умеет

**Покупателю:**
- 🛍 Каталог с фото, описанием и коллекцией
- 👀 «Покажи что внутри» — комплектация и до 10 фото (кнопка есть, только если заполнено)
- 🎨 Цветные кнопки (зелёные/синие/красные — Telegram Premium не нужен)
- 🛒 Корзина: добавить / убрать **по одной штуке** / очистить (с подтверждением)
- 🎁 **От 2 брелоков — скидка 10%** на брелоки
- 🚚 **Брелоков на 1000 ₽ и больше — доставка бесплатно** (сумма считается только по брелокам, без доставки)
- 🚚 Иначе доставка — **389 ₽**
- ⭐ Кнопка «Отзывы» — ведёт в вашу группу с отзывами
- 💬 Комментарий к заказу (пожелания по доставке)
- 💳 Оплата картой через ЮKassa прямо в боте
- 📦 «Мои заказы» — текущие и история, трек-номер
- ✅ Кнопка «Я получил заказ»

**Админу (`/admin`):**
- 📋 Все заказы + карточка каждого
- 🚚 «Отправить» → ввод трек-номера → статус «В пути»
- ✅ «Отметить доставленным»
- ❌ «Отменить заказ»
- ➕ Добавить товар (название, описание, цена, фото, коллекция, «что внутри»)
- 📦 Управление товарами: **изменить** (название, описание, цену, фото, коллекцию, «что внутри»), снять/вернуть в продажу, удалить (с подтверждением)
- 🟦 Заказы и сообщения в поддержку из ВКонтакте — с кнопкой «↩️ Ответить»
- 👤 «Режим пользователя» — посмотреть магазин глазами покупателя
- 🔔 Уведомление о каждом новом заказе

## 🔄 Статусы заказа

| Статус | Кто ставит | Когда |
|---|---|---|
| ⏳ Ожидает оплаты | бот | заказ создан, ждём оплату (только с ЮKassa) |
| 🆕 Новый (оплачен) | бот / вы | оплата прошла |
| 🚚 В пути | вы | добавили трек-номер |
| ✅ Доставлен | вы или покупатель | заказ получен |
| ❌ Отменён | вы | отмена |

## 🚀 Запуск (локально)

### 1. Установите Python 3.11+ и создайте окружение

```bash
cd ssarafos_final
python -m venv .venv

# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Заполните `.env`

Скопируйте `.env.example` в `.env` и впишите свои значения:

```bash
cp .env.example .env      # Windows: copy .env.example .env
```

| Переменная | Обязательна | Что это |
|---|---|---|
| `BOT_TOKEN` | ✅ да | токен от [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | ✅ да | ваш числовой Telegram ID (узнать в [@userinfobot](https://t.me/userinfobot)) |
| `BOT_USERNAME` | желательно | username бота **без @** (для возврата после оплаты) |
| `SUPPORT_USERNAME` | нет | username поддержки **без @** |
| `REVIEWS_URL` | желательно | ссылка на группу с отзывами (`https://t.me/...`, `t.me/...` или `@...`) |
| `DB_PATH` | нет | путь к базе (по умолчанию `data/shop.db`) |
| `DELIVERY_COST` | нет | стоимость доставки (по умолчанию 389) |
| `FREE_DELIVERY_SUM` | нет | от какой суммы брелоков (₽) доставка бесплатна (1000) |
| `DISCOUNT_FROM_QTY` | нет | от скольких брелоков скидка (2) |
| `DISCOUNT_PERCENT` | нет | размер скидки (10) |
| `SYNC_API_TOKEN` | для ВК | токен API для бота ВК (пусто — API выключено) |
| `SYNC_API_PORT` | для ВК | порт API (по умолчанию `PORT` или 8080) |
| `YOOKASSA_SHOP_ID` | нет | Shop ID из личного кабинета ЮKassa |
| `YOOKASSA_SECRET` | нет | секретный ключ ЮKassa |

> ℹ️ Старые переменные `FREE_DELIVERY_FROM` и `DISCOUNT_FROM` больше **не используются** —
> их можно удалить из `.env` и из настроек хостинга.

> ⚠️ **Важно:** `ADMIN_ID` должен быть именно вашим ID. Если указать чужой —
> админка не откроется. Проверить: `@userinfobot`.

### 4. Запустите

```bash
python bot.py
```

В логах должно появиться:
```
База данных инициализирована ✅
ЮKassa: ключи найдены, онлайн-оплата включена ✅   (или «оплата отключена»)
Бот запущен 🚀
```

## 🚀 Запуск на хостинге (Bothost и подобные)

1. Залейте файлы в GitHub-репозиторий (**без `.env`** — он в `.gitignore`).
2. В панели хостинга задайте переменные окружения (тот же список, что в таблице выше).
3. Для `DB_PATH` на хостинге удобнее указать `DATA_DIR=/app/data` — тогда база ляжет в `/app/data/shop.db`.
4. Стартовый файл: **`bot.py`**.
5. ⚠️ Запускайте **только один экземпляр** бота. Если держите бота на хостинге — не запускайте его же локально, иначе появится ошибка `Conflict: terminated by other getUpdates request`.

## 💳 Подключение ЮKassa

Пока `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET` пусты — бот работает **без оплаты**:
заказ сразу попадает админу в статусе «Новый».

Чтобы включить оплату:
1. Зарегистрируйтесь на [yookassa.ru](https://yookassa.ru) и получите **Shop ID** и **секретный ключ**.
2. Впишите их в `.env` (или в переменные окружения на хостинге).
3. Перезапустите бота.

Как это работает у покупателя:
1. Оформляет заказ → бот создаёт платёж в ЮKassa.
2. Покупатель жмёт **«💳 Оплатить»** → платит на стороне ЮKassa.
3. Возвращается в бот и жмёт **«✅ Проверить оплату»** → бот проверяет статус.
   Если оплата ещё не прошла, кнопка **«💳 Оплатить» остаётся на месте** — случайное нажатие ничего не ломает.
4. Оплата прошла → заказ уходит вам в статусе «🆕 Новый (оплачен)».
5. Платёж отменён или истёк → заказ отменяется автоматически, товары возвращаются покупателю в корзину, вам приходит уведомление.
6. Ссылка на оплату также есть в разделе «📦 Мои заказы».

Webhook не нужен — оплата подтверждается по кнопке.

## 👀 «Покажи что внутри»

Необязательный блок у товара: описание комплектации и до 10 фото.
- При добавлении товара — шаги 6 и 7 (можно пропустить словом «нет» / кнопкой «Готово»).
- У существующего товара: «📦 Управление товарами» → товар → «✏️ Изменить товар» → «👀 Покажи что внутри».
- Фото можно отправлять по одному или сразу альбомом. Новые фото **заменяют** старые.
- Если ни текста, ни фото нет — покупатель кнопку не видит. Старые товары в базе работают как раньше.

## 🟦 Бот ВКонтакте

Telegram-бот — главный: бот ВК берёт у него каталог и отправляет заказы и сообщения поддержки.
Чтобы включить связь, задайте `SYNC_API_TOKEN` (и при необходимости `SYNC_API_PORT`).
Подробности и все запросы — в **[SYNC_API.md](SYNC_API.md)**.

На Bothost у бота есть публичный адрес вида `https://bot-123.bothost.ru` — его и токен
нужно будет указать в боте ВК. Уточните в панели хостинга, на какой порт проксируется этот адрес.

## 🔧 Частые проблемы

**`InvalidToken` / `You must pass the token`**
Не заполнен `BOT_TOKEN` в `.env`. Либо в файле лишние пробелы/кавычки.

**`Conflict: terminated by other getUpdates request`**
Запущено **два** бота с одним токеном. Остановите один (или создайте второго бота у @BotFather).

**`/admin` пишет «Нет доступа»**
`ADMIN_ID` не совпадает с вашим реальным ID. Проверьте через @userinfobot и перезапустите бота.

**Кнопка «◀️ К моим заказам» не работает**
Было в старой версии — в этой версии обработчик зарегистрирован. Просто используйте файлы из архива целиком, не подменяйте по частям.

**`PTBUserWarning: If 'per_message=False'...`**
Это предупреждение, а не ошибка. В этой версии оно отключено — в логах чисто.

**«Заказ оплачен», но у админа статус «Ожидает оплаты»**
Покупатель не нажал «✅ Проверить оплату». Проверить оплату можно вручную в личном кабинете ЮKassa.

## 🧪 Что проверено

- Расчёт: 1×500 → +389 ₽ · 2×450 (900 ₽) → −10%, доставка 389 ₽ · 2×500 (1000 ₽) → −10% и доставка бесплатно · 1×1200 → доставка бесплатно без скидки
- Кнопка «Убрать» убирает ровно одну штуку; «Очистить корзину» спрашивает подтверждение
- Изменение каждого поля товара, отмена изменения, защита от не-админа
- «Проверить оплату» при неоплаченном заказе, таймауте и ошибке ЮKassa — ссылка на оплату остаётся
- Повторные нажатия не создают дублей заказов и уведомлений
- Если покупатель изменил корзину или админ цену до «Подтвердить» — бот показывает новую сводку
- Брошенный на полпути диалог не перехватывает текст другого действия
- «Что внутри»: без него кнопки нет; альбомы, лимит 10 фото, замена, отмена, удаление
- Старая база данных открывается новой версией без потерь
- API для ВК: токен, каталог и фото, расчёт корзины, заказы без дублей, оплата, статусы, поддержка и ответы
