# 🛍 SSARAFOS — Telegram-магазин брелоков

Готовый бот: каталог, корзина, оформление заказа, онлайн-оплата через ЮKassa
и админ-панель со статусами заказов.

---

## ✨ Что умеет

**Покупателю:**
- 🛍 Каталог с фото, описанием и коллекцией
- 🛒 Корзина: добавить / убрать / очистить
- 🚚 Доставка **389 ₽ только за 1 брелок**
- 🎉 **От 2 брелоков — доставка бесплатно**
- 🎁 **От 3 брелоков — скидка 10%** на товары
- 💬 Комментарий к заказу (пожелания по доставке)
- 💳 Оплата картой через ЮKassa прямо в боте
- 📦 «Мои заказы» — текущие и история, трек-номер
- ✅ Кнопка «Я получил заказ»

**Админу (`/admin`):**
- 📋 Все заказы + карточка каждого
- 🚚 «Отправить» → ввод трек-номера → статус «В пути»
- ✅ «Отметить доставленным»
- ❌ «Отменить заказ»
- ➕ Добавить товар (название, описание, цена, фото, коллекция)
- 📦 Управление товарами (снять/вернуть в продажу, удалить)
- 👤 «Режим пользователя» — посмотреть магазин глазами покупателя
- 🔔 Уведомление о каждом новом заказе

---

## 🔄 Статусы заказа

| Статус | Кто ставит | Когда |
|---|---|---|
| ⏳ Ожидает оплаты | бот | заказ создан, ждём оплату (только с ЮKassa) |
| 🆕 Новый (оплачен) | бот / вы | оплата прошла |
| 🚚 В пути | вы | добавили трек-номер |
| ✅ Доставлен | вы или покупатель | заказ получен |
| ❌ Отменён | вы | отмена |

## 🚀 Запуск (локально)

### 1. Установите Python 3.11+ и создайте окружение

```bash
cd ssarafos_final
python -m venv .venv

# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Заполните `.env`

Скопируйте `.env.example` в `.env` и впишите свои значения:

```bash
cp .env.example .env      # Windows: copy .env.example .env
```

| Переменная | Обязательна | Что это |
|---|---|---|
| `BOT_TOKEN` | ✅ да | токен от [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | ✅ да | ваш числовой Telegram ID (узнать в [@userinfobot](https://t.me/userinfobot)) |
| `BOT_USERNAME` | желательно | username бота **без @** (для возврата после оплаты) |
| `SUPPORT_USERNAME` | нет | username поддержки **без @** |
| `DB_PATH` | нет | путь к базе (по умолчанию `data/shop.db`) |
| `DELIVERY_COST` | нет | стоимость доставки (по умолчанию 389) |
| `FREE_DELIVERY_FROM` | нет | от скольких брелоков доставка бесплатна (2) |
| `DISCOUNT_FROM` | нет | от скольких брелоков скидка (3) |
| `DISCOUNT_PERCENT` | нет | размер скидки (10) |
| `YOOKASSA_SHOP_ID` | нет | Shop ID из личного кабинета ЮKassa |
| `YOOKASSA_SECRET` | нет | секретный ключ ЮKassa |

> ⚠️ **Важно:** `ADMIN_ID` должен быть именно вашим ID. Если указать чужой —
> админка не откроется. Проверить: `@userinfobot`.

### 4. Запустите

```bash
python bot.py
```

В логах должно появиться:
```
База данных инициализирована ✅
ЮKassa: ключи найдены, онлайн-оплата включена ✅   (или «оплата отключена»)
Бот запущен 🚀
```

## 🚀 Запуск на хостинге (Bothost и подобные)

1. Залейте файлы в GitHub-репозиторий (**без `.env`** — он в `.gitignore`).
2. В панели хостинга задайте переменные окружения (тот же список, что в таблице выше).
3. Для `DB_PATH` на хостинге удобнее указать `DATA_DIR=/app/data` — тогда база ляжет в `/app/data/shop.db`.
4. Стартовый файл: **`bot.py`**.
5. ⚠️ Запускайте **только один экземпляр** бота. Если держите бота на хостинге — не запускайте его же локально, иначе появится ошибка `Conflict: terminated by other getUpdates request`.

## 💳 Подключение ЮKassa

Пока `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET` пусты — бот работает **без оплаты**:
заказ сразу попадает админу в статусе «Новый».

Чтобы включить оплату:
1. Зарегистрируйтесь на [yookassa.ru](https://yookassa.ru) и получите **Shop ID** и **секретный ключ**.
2. Впишите их в `.env` (или в переменные окружения на хостинге).
3. Перезапустите бота.

Как это работает у покупателя:
1. Оформляет заказ → бот создаёт платёж в ЮKassa.
2. Покупатель жмёт **«💳 Оплатить»** → платит на стороне ЮKassa.
3. Возвращается в бот и жмёт **«✅ Я оплатил»** → бот проверяет статус.
4. Оплата прошла → заказ уходит вам в статусе «🆕 Новый (оплачен)».
5. Ссылка на оплату также остаётся в разделе «📦 Мои заказы».

Webhook не нужен — оплата подтверждается по кнопке. Шаблоны возвращаются в MAX и другие соцсети независимо.

## 🔧 Частые проблемы

**`InvalidToken` / `You must pass the token`**
Не заполнен `BOT_TOKEN` в `.env`. Либо в файле лишние пробелы/кавычки.

**`Conflict: terminated by other getUpdates request`**
Запущено **два** бота с одним токеном. Остановите один (или создайте второго бота у @BotFather).

**`/admin` пишет «Нет доступа»**
`ADMIN_ID` не совпадает с вашим реальным ID. Проверьте через @userinfobot и перезапустите бота.

**Кнопка «◀️ К моим заказам» не работает**
Было в старой версии — в этой версии обработчик зарегистрирован. Просто используйте файлы из архива целиком, не подменяйте по частям.

**`PTBUserWarning: If 'per_message=False'...`**
Это предупреждение, а не ошибка. В этой версии оно отключено — в логах чисто.

**«Заказ оплачен», но у админа статус «Ожидает оплаты»**
Покупатель не нажал «✅ Я оплатил». Проверить оплату можно вручную в личном кабинете ЮKassa.
